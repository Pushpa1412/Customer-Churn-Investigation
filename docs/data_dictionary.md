# Data Dictionary

The CSV is generated by `src/generate_data.py`. It is fully synthetic and contains no real customer information.

| Column | Type | Description |
|---|---|---|
| customer_id | string | Synthetic unique customer identifier |
| tenure_months | integer | Number of months the customer has subscribed |
| monthly_charges | float | Simulated monthly subscription charge |
| contract_type | category | Month-to-month, One year, or Two year |
| support_tickets | integer | Simulated number of support tickets in the observation period |
| payment_method | category | Card, Bank transfer, or Digital wallet |
| churn | integer | Target label: 1 = churned, 0 = retained |

## Generator assumptions
The generator deliberately creates plausible relationships for learning purposes: short-tenure and month-to-month customers are assigned higher churn probability, and higher support-ticket counts can increase that probability. These are assumptions built into the simulation, not discovered facts about real customers.
